SHEET 01

The Set — The Unique Bin

A Set is like a high-security club guest list: No duplicates allowed. If you try to add the same item twice, the set just ignores the second one.

COMPONENT SPEC // set { }
# Build a set with curly braces
inv = {"Sword", "Shield", "Sword"}

print(inv) 
# Output: {'Sword', 'Shield'}  <-- The extra Sword is gone!
Real World Alignment: Think of a set of Unique Usernames. Two people can't have the exact same name, so a Set is perfect for storing them.

SHEET 02

The Dictionary — Labeled Storage

A List is like a stack of boxes you have to count (0, 1, 2...). A Dictionary is a cabinet where every drawer has a Label (Key).

ASSEMBLY SPEC // dict { key : value }
# RPG Character Data
player = {
    "name": "Ninja",
    "hp": 100,
    "level": 5
}

print(player["hp"]) # Result: 100
Real World Alignment: Your Phone Contacts. The "Key" is the Name (Alex), and the "Value" is the Number (0412...). You find the number by looking up the name label!

SHEET 03

Conditionals — Decision Gates

Conditionals are like Traffic Lights for your code. Python checks a condition: if it's True, it follows that path. Only one path can win!

CIRCUIT SPEC // if / elif / else
money = 10
if money >= 20:
    print("Buy Game")
elif money >= 10:
    print("Buy Candy") # This path is True!
else:
    print("Save money")
The Gap Rule: Notice the space before print? That's called Indentation. Without that space, Python doesn't know which code belongs to which decision!

SHEET 04

Loops — The Cycle Machine

A loop is like a Washing Machine. It repeats the same action (Wash, Rinse, Spin) until the timer hits zero or a condition is met.

CONTROL SPEC // break / continue
# BREAK = Stop the machine NOW!
for n in range(10):
    if n == 3:
        break # Machine shuts down here.
    print(n) # Output: 0, 1, 2
ICT Strategy: Use break if you found the item you were looking for and don't need to keep searching. Use continue to skip one "bad" item but keep the loop running.

SHEET 05

Functions — The Reusable Button

A Function is a block of code you design once and save for later. It's like a Microwave Button. You program it once to "Popcorn," then you just press the button every time you want popcorn.

MODULE SPEC // def name()
# DEFINE the 'Popcorn' button logic
def cook_popcorn():
    print("Heating...")
    print("Pop! Pop! Pop!")

# Press the button (Call the function)
cook_popcorn()
The Power of Modules: Imagine if you had to write 100 lines of code every time your character jumped in a game. Instead, you write it once in a def jump(): function and just "call" it when the spacebar is pressed!
